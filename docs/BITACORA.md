# BITÁCORA

Cada jornada de prospección se registra en la base **Bitácora de Prospección**
(en *Workspace Comercial — PAGX Studio*).

Permite mantener contexto aunque pasen semanas: qué se hizo, a quién se encontró,
qué se envió y qué pasó después.

## Un registro por jornada

| Propiedad | Qué poner |
|---|---|
| **Jornada** (título) | `DD/MM/AAAA — <Responsable>` (ej. `08/09/2026 — Alan`). |
| **Fecha** | La fecha de la jornada. |
| **Responsable** | Sergio / Alan. |
| **Empresas investigadas** | Total tocadas ese día (antes de filtrar). |
| **Empresas descartadas** | Cuántas se descartaron. |
| **Empresas auditadas** | Cuántas llegaron a `Auditado`. |
| **Candidatos finales** | Cuántas quedaron como candidatas del día (máx. 4). |
| **Contactos realizados** | Cuántos mensajes envió Sergio ese día (0 si ninguno). |
| **Prospectos trabajados** | Relación → las fichas de `Prospectos` de ese día. |
| **Observaciones** | Resumen ejecutivo: mejores oportunidades, patrones, decisiones. |
| **Aprendizajes del día** | Qué patrón se vio, qué funcionó, qué evitar la próxima. |

En el **cuerpo de la página** de cada jornada se puede pegar el detalle:
lista de investigados, tabla de finales con score, runners-up, etc.
La entrada del `07/09/2026` sirve de plantilla.

## Regla

La bitácora **no reemplaza** la trazabilidad de cada ficha (esa vive en las
propiedades del prospecto: fechas, "por quién", estado). La bitácora es el
**diario**: el "qué hicimos hoy" a nivel de jornada.
